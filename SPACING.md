# Вертикальный ритм — как устроен пульт

Все расстояния между блоками страницы управляются **тремя переменными**
в `src/styles/tokens.base.css` (блок «ВЕРТИКАЛЬНЫЙ РИТМ СТРАНИЦЫ»):

| Ручка | Что делает | Обычный диапазон |
|---|---|---|
| `--section-gap` | отступ секции сверху и снизу (штатный) | 24–44px |
| `--section-gap-roomy` | то же для акцентных/полотенных блоков (тёмная полоса, истории) | 40–64px |
| `--head-gap` | заголовок секции → её контент (все `.sec-head`-шапки) | 20–28px |

**Правило иерархии:** внешнее расстояние (между секциями, 2×`--section-gap`)
всегда БОЛЬШЕ внутреннего (`--head-gap`). Блоки должны «слипаться» внутри
и отделяться друг от друга, а не наоборот.

**Главная ловушка:** секции встык дают визуальный разрыв = **2 × ручка**
(низ верхней секции + верх нижней). Хочешь дырку 48px — ставь 24px.

## Правила

1. Секции читают ТОЛЬКО переменные: `.sec { padding-block: var(--section-gap) }`.
   Никаких своих цифр в компонентах.
2. Резина — через `clamp(мобила, vw, десктоп)` прямо в значении переменной.
3. Точечные отклонения — классами-модификаторами (`.sec--tight`, `.sec--flush-top`),
   а не правкой общей переменной и не inline-цифрой.
4. Горизонтальные поля — отдельный механизм: контейнер `.wrap` в `global.css`
   (~4% с краёв, ≤640px → 16px). В секциях только `padding-block`.

## Перенос на следующий сайт

Скопировать блок переменных из `tokens.base.css` + правило `.sec`/`.wrap`
из `global.css`, подобрать значения под макет. Компоненты не трогаются.

**Когда просят «поменять расстояния между блоками» — крутить переменную,
а не отдельные секции.**
